# MAX Chat · GREEN-API (тестовое задание)

Минималистичный веб-чат на **React + Vite** для отправки и получения текстовых
сообщений в мессенджере **MAX** через **GREEN-API**. Интерфейс ориентирован на
[web.max.ru](https://web.max.ru/): список чатов слева, переписка справа.

Сделано в рамках тестового задания «Фронтенд разработчик React».

## Возможности

- Вход по `idInstance` / `apiTokenInstance` (проверяются запросом `GetStateInstance`)
- Создание нового чата по номеру телефона получателя
- Отправка текстовых сообщений — метод [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)
- Получение входящих сообщений в реальном времени — long polling
  [`ReceiveNotification` / `DeleteNotification`](https://green-api.com/v3/docs/api/receiving/technology-http-api/)
- История переписки и учётные данные сохраняются в `localStorage` браузера
  (никакого бэкенда — запросы уходят из браузера напрямую в GREEN-API)

Список того, что **сознательно не реализовано** (см. требование задания
«максимально простой интерфейс с минимальным набором функций»): вложения,
группы, статусы прочтения, редактирование/удаление сообщений, несколько
устройств одновременно.

## Стек

React 19, Vite, обычный CSS (без UI-фреймворков и стейт-менеджеров — для
такого объёма функциональности они избыточны).

## Локальный запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Для сборки продакшен-версии:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Зарегистрируйте инстанс в [личном кабинете GREEN-API](https://console.green-api.com/)
   и авторизуйте его приложением MAX (раздел инстанса → подключение / QR-код).
   Если тестируете без доступа к MAX, задание допускает WhatsApp — процесс
   авторизации инстанса аналогичен, менять код не нужно.
2. **Важно:** в настройках инстанса (`SetSettings` или личный кабинет) поле
   `webhookUrl` должно быть пустым, а получение входящих сообщений включено —
   иначе уведомления не попадут в очередь `ReceiveNotification`.
3. Откройте приложение, введите `idInstance` и `apiTokenInstance` из личного
   кабинета. Если у инстанса указан отдельный хост API, разверните
   «Указать другой хост apiUrl» и впишите его — иначе используется общий
   `https://api.green-api.com`.
4. Нажмите «Новый чат», укажите номер телефона получателя в международном
   формате без «+» (например `79991234567`).
5. Напишите сообщение и отправьте. Ответ собеседника из мессенджера появится
   в чате автоматически, без обновления страницы.

## Структура проекта

```
src/
  api/greenApi.js               # HTTP-клиент GREEN-API (send/receive/check)
  hooks/useIncomingMessages.js  # long polling входящих уведомлений
  context/AuthContext.jsx       # хранение и проверка учётных данных
  utils/storage.js              # персистентность в localStorage
  components/                   # LoginForm, Sidebar, ChatWindow, MessageBubble, NewChatModal
  App.jsx                       # состояние чатов и связка компонентов
```

## Известные ограничения GREEN-API, учтённые в реализации

- `ReceiveNotification` — это общая очередь уведомлений инстанса: если запустить
  два экземпляра приложения на одном инстансе одновременно, они будут
  «отбирать» уведомления друг у друга. Для теста это некритично.
- Каждое полученное уведомление обязательно удаляется через
  `DeleteNotification`, иначе оно будет возвращаться повторно.
- Дедупликация сообщений сделана по `idMessage`, чтобы сообщение не
  задваивалось, если, например, было отправлено с телефона и одновременно
  прилетело уведомление о нём.
